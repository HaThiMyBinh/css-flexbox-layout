Main Content

Chào mừng bạn đến với bài thực hành xây dựng bố cục trang web hoàn chỉnh bằng CSS Flexbox!

Nguyên lý phân chia bố cục Flexbox:

  • Khung cha (.container): Thiết lập display: flex; flex-direction: column; để sắp xếp Header, Nav, Main-Container và Footer theo chiều dọc.
  • Vùng giữa (.main-container): Thiết lập display: flex; flex: 1; chiếm toàn bộ khoảng trống còn lại giữa Header và Footer.
  • Phần nội dung (.content): Có flex: 3; (chiếm 75% chiều rộng hàng ngang trên Desktop).
  • Phần cột phụ (.sidebar): Có flex: 1; (chiếm 25% chiều rộng hàng ngang trên Desktop).
